HTML-first starter

Launch a sharp static site without framework weight.

Use this starter as a practical base: semantic routes, responsive layout primitives, reusable components, optimized images, and built-in discovery files.

Ready in minutes 2 routes

Home and components pages are intentionally small, readable, and safe to replace.

Edit routes

Change files in src/pages. One HTML file becomes one public URL with SEO and route data.

Compose sections

Use built-in components for cards, actions, images, accordions, code, grids, and markdown.

Ship static output

Run Bun checks, then deploy generated files from dist with your host of choice.

Design baseline

Neutral, flexible, and ready for brand work.

Tokens define spacing, type, colors, borders, and motion. Keep global CSS for primitives; move component-specific styles into component files.

Starter workflow

01

Update config

Set site name, URL, description, locale, and social image in src/site.json.

02

Replace pages

Edit src/pages/index.html, add nested pages, and keep route markup semantic.

03

Add content

Use HTML, components, images, or opt into markdown-backed content when needed.

04

Verify

Run bun run check before handoff so broken links and component issues fail early.
