Purpose: give agents one deterministic source for built-in component contracts, slots, variants, schema metadata, accessibility notes, and valid usage examples before editing routes or inventing patterns.

See `framework/docs/components.md` in the framework package for the authoring contract.

## Accordion

Native <details> disclosure. Multiple accordions sharing the same group name are mutually exclusive.

### Contract

- Tag: `<Accordion>` can be self-closing.
- Slots: none detected.
- Unknown attributes: rejected when schema exists.

### Attributes

| Name | Required | Type / enum | Description |
|---|---|---|---|
| `summary` | no | string | Visible summary text (the toggle row). Defaults to Details. |
| `body` | no | string | Disclosed body content. May be HTML. |
| `group` | no | string | Optional shared name for exclusive grouping (uses <details name>). |
