## Accordion

Native <details> disclosure. Multiple accordions sharing the same group name are mutually exclusive.

### Contract

- Tag: `<Accordion>` can be self-closing.
- Slots: none detected.
- Unknown attributes: rejected when schema exists.

### Attributes

| Name | Required | Type / enum | Description |
|---|---|---|---|
| `summary` | no | string | Visible summary text (the toggle row). Defaults to Details. |
| `body` | no | string | Disclosed body content. May be HTML. |
| `group` | no | string | Optional shared name for exclusive grouping (uses <details name>). |

### Accessibility notes

- Use clear `summary` text; `group` makes matching disclosures mutually exclusive.

### Example

```html
<Accordion summary="Question?" body="Answer copy." />
```

## Image

Responsive WebP image. Lazy by default with temporary .img-tmp preview; eager images skip preview. Master in an image source root; build emits optimized /assets/images/{src}.webp variants.

### Contract

- Tag: `<Image>` can be self-closing.
- Slots: none detected.
- Unknown attributes: rejected when schema exists.

### Attributes

| Name | Required | Type / enum | Description |
|---|---|---|---|
| `src` | yes | string | Unique logical image name (basename without extension). |
| `alt` | yes | string | Alt text. Use alt="" for decorative. |
| `max` | no | string | Max long edge in px. Default 1200. |
| `quality` | no | string | WebP quality 1-100. Default 82. |
| `loading` | no | `lazy \| eager` | Default lazy. Use eager for above-fold. |
| `sizes` | no | string | CSS sizes attribute. Default 100vw when responsive. |
| `responsive` | no | `true \| false` | Set false to opt out of srcset emission. Default true. |
| `width` | no | string | Override intrinsic width. |
| `height` | no | string | Override intrinsic height. |

### Variants / enums

- `loading`: `lazy`, `eager`
- `responsive`: `true`, `false`

### Accessibility notes

- `alt` is required; use `alt=""` only for decorative images.

### Example

```html
<Image src="hero" alt="Product interface" max="1200" />
```
