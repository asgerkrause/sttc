HTML-first sites, composed at build time.

Write routes, drop in components, and ship static output. No runtime framework required.

Built-in patterns

Content

Cards, markdown, accordions, code blocks, and images.

Layout

Sections, grids, stack rhythm, and global primitives stay predictable.

Publishing

Build emits static HTML, optimized images, feeds, sitemap, and discovery files.

Template directives

Use conditionals inside components, and loops inside CMS templates.

Component fallback

`{:else}` renders fallback markup when an optional attr or slot is empty.

<!-- src/components/Badge.html --> <span class="badge"> {#if icon} <span>{{icon}}</span> {:else} <span>•</span> {/if} {{label}} </span>

CMS list loop

`{#each}` loops YAML front-matter arrays in `src/templates/*.html`.

--- title: Services services: - title: Strategy body: Positioning and structure. - title: Build body: Static site implementation. --- <Grid> {#each services as service, i} <Card title="{{service.title}}"> <p>{{service.body}}</p> </Card> {/each} </Grid>
