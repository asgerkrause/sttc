Component gallery

Copy-ready patterns using built-in pieces.

These examples cover common page needs: actions, cards, media, disclosures, markdown, code, and layout primitives.

Slot-first patterns stay flexible: compose primitives inside Section, Grid, and Card instead of locking content into too many props.

Naming

Preset naming

Future content presets use readable nouns. Plural components wrap collections; singular components are items. Most should stay slot-first so existing primitives compose inside them.
