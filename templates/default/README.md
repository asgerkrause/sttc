# SANITIZE Boilerplate site

Client site starter powered by `@snz/bp`.

Created with:

```bash
create-snz-bp my-client
# or inside empty directory
create-snz-bp .
```

Ships with:

- `/` — generic landing page
- `/components/` — built-in component gallery
- no demo marketing routes (add your own with `bun run new route about`)

## Commands

```bash
bun install
bun run dev
bun run build
bun run check
```

Edit `src/`, `content/`, and `media/`. Do not edit `dist/`.
